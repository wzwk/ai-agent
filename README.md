# AI Agent

这是一个面向本地多项目代码库的智能问答 Agent，用于根据自然语言问题检索代码、追踪调用链，并结合文档与向量检索生成有依据的回答。

## 主要能力

- 多项目识别与自动路由
- 关键词检索和向量检索结合
- 跨服务调用链追踪与完整性检查
- FAQ、Markdown 文档和源码联合检索
- 语义缓存与流式回答
- RAG 索引任务管理

## 代码结构

- `src/main/java`：Agent、检索、RAG、模型调用和接口实现
- `src/main/resources`：应用配置、通用项目示例和前端页面
- `src/test/java`：核心检索、索引和调用链测试

本仓库用于展示个人编写的核心源码，不包含运行密钥、内部项目资料、日志、数据、部署脚本和第三方压缩代码。
